# Kasa

Application web de location d'appartements entre particuliers, développée en React.
Projet front-end intégrant des maquettes Figma responsives, avec gestion des routes
via React Router et consommation de données en JSON (back-end non disponible).

## Stack technique
- React
- React Router
- Vite
- Sass

## Fonctionnalités
- Navigation entre les pages (accueil, à propos, fiche logement, page 404)
- Affichage dynamique des annonces à partir d'un fichier JSON
- Composants réutilisables (carrousel, collapse, bannière, etc.)
- Design responsive conforme aux maquettes Figma

## Contexte
Projet réalisé dans le cadre de la formation Développeur Web d'OpenClassrooms.
